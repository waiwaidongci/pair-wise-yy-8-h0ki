# 古法纸浆发酵与洗浆领用

运行：

```bash
npm start
```

访问 `http://localhost:3039`。数据保存在 `data/paper-pulp-fermentation.json`。

## 规则

- **批次规则**：批次只记发酵天数和状态（入缸 / 发酵中 / 可抄纸 / 异常观察）。
- **洗浆复核**：进入「可抄纸」后逐缸登记洗浆水量、滤水浊度、操作人与复核时间。
  - 水量每斤纸浆不少于 2 升，浊度不高于二度；水量不足或浊度超标即判「待复洗」，不能领用、不占领用量。
  - 换人连续两次合格、相隔满 4 小时，批次状态为「可领用」。
- **领用台账**：领用量不得超过剩余浆量；领用后对应两次洗浆记录被更正（原许可失效，需重新复核），旧领用单长期保留可查。
- 批次、洗浆记录、领用台账分表维护；页面支持按「待复洗」「可领用」等状态筛选。
